## Descrição

Add social icons to your WooCommerce emails.

## Como instalar?

1. Acesse o painel de administração do WordPress e vá para **Plugins > Adicionar Novo**.
2. Pesquise por "Social Icons for WooCommerce Emails".
3. Encontre o plugin, clique em **Instalar Agora** e depois em **Ativar**.
4. Vá em **WooCommerce > Configurações > E-mails** para configurar o plugin.
